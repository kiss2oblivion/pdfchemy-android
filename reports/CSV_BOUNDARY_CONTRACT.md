# CSV boundary contract

Reference: Gemini PR #12, `5c1308ccfb3062d23918f14d734f17e417e77888`, [published parser](https://github.com/kiss2oblivion/pdfchemy-android/blob/5c1308ccfb3062d23918f14d734f17e417e77888/pdf-ipc/src/main/java/com/pdfchemy/app/logic/CsvParser.kt) and [fixtures](https://github.com/kiss2oblivion/pdfchemy-android/blob/5c1308ccfb3062d23918f14d734f17e417e77888/app-host/src/test/java/com/pdfchemy/app/ui/TableExtractorCorrectnessTest.kt). Adopt the published semantics; no Gemini-owned implementation is copied into production or edited. The shared validation directory contains `CODEX_CSV_COORDINATION_2026-10-29.md` and read-only reference snapshots. This records the reference contract, not a new private approval.

The IPC validator returns the original text without constructing rows/cells. Empty input is zero records. Empty fields and blank/whitespace-only records count. A final separator adds no extra record. Commas delimit fields; CR, LF and CRLF separate records outside quotes. Quoted CR/LF/CRLF, commas, whitespace and doubled quotation marks are preserved. Ragged rows are permitted. Bare quotes, unclosed quoted fields and characters after a closing quote other than delimiter/separator/EOF are rejected.

Quotas remain 2 MiB encoded file / text character bound, 5,000 logical records, 128 columns per record, 1,024 decoded UTF-16 characters per cell and 20,000 total cells. Escaped double quotes count once; embedded CRLF counts two cell characters. File reads are bounded even if the file grows after inspection. Completed immutable host CSV snapshots are checked before worker ACK and destination publication; no worker pathname reopen is used.

Local differential verification compiles a read-only snapshot of the published parser as test-only code outside the checkout. Three parity tests cover 12 decoded golden fixtures, six malformed quote fixtures, eight boundary quota fixtures and all **55,987** inputs of length zero through six over `a`, space, comma, quote, CR and LF. Repo-owned golden and boundary tests run in normal CI. The external oracle is evidence for this pinned revision, not proof of future cross-branch parity; integration must rerun these fixtures if the parser changes.
